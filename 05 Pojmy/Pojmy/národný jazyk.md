# 🔑 národný jazyk

Národný jazyk je nadradený pojem zahŕňajúci všetky jazykové útvary národa – spisovnú, štandardnú a subštandardnú formu, ako aj nárečia. Slovenčina patrí do indoeurópskej jazykovej rodiny, slovanskej vetvy, západoslovanskej skupiny.
