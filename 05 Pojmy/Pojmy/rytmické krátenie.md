# 🔑 rytmické krátenie

Rytmické krátenie je pravidlo, podľa ktorého po dlhej [[slabika|slabike]] nemôže vo vnútri slovného tvaru nasledovať ďalšia dlhá [[slabika]], napr. múdry → múdrych, nie múdrých. Výnimky tvoria napr. slová výhier, lístie, chvália alebo slová s predponami ná-, zá-, sú-.
