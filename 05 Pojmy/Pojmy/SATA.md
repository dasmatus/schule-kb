# 🔑 SATA

SATA je štandardné rozhranie na pripojenie [[HDD|pevných diskov]] a SSD k [[Základná doska|základnej doske]] pomocou kábla. Nahradilo staršie rozhranie IDE a je pomalšie ako pripojenie SSD cez M.2/[[PCIe slot|PCIe]].
