# 🔑 DHCP

DHCP automaticky poskytuje klientovi IP konfiguráciu, najmä IP adresu, prefix alebo masku, predvolenú bránu, DNS a dobu prenájmu. Pri IPv4 klient a server používajú postup DORA: Discover, Offer, Request, Acknowledge. DHCPv6 môže prideľovať IPv6 adresy a ďalšie voľby.
