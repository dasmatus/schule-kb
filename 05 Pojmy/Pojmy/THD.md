# 🔑 THD

THD (Total Harmonic Distortion, celkové harmonické skreslenie) udáva, akú časť prúdu alebo napätia tvoria vyššie harmonické zložky oproti základnej harmonickej. Pre [[Lineárna záťaž|lineárnu záťaž]] je THD približne 0 %, zatiaľ čo pri nelineárnej záťaži môže dosahovať desiatky až stovky percent.
