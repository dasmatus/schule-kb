# 🔑 prísudok

Prísudok (predikát) je hlavný [[vetný člen]] vyjadrujúci dej, stav alebo vlastnosť [[podmet|podmetu]]; spolu s [[podmet|podmetom]] tvorí vetný základ v prisudzovacom vzťahu. Môže byť jednoduchý slovesný (Chlapec beží.) alebo zložený slovesno-menný (Chlapec je šikovný.).
