# 🔑 Aritmetická postupnosť

**Aritmetická postupnosť (AP)** je [[Postupnosť|postupnosť]], v ktorej je rozdiel dvoch po sebe idúcich členov konštantný. Tento rozdiel sa nazýva **diferencia** $d$:

$$a_{n+1} = a_n + d, \qquad d = a_{n+1}-a_n.$$

Všeobecný člen a prechod medzi členmi:

$$a_n = a_1 + (n-1)d, \qquad a_k = a_n + (k-n)d.$$

Súčet prvých $n$ členov:

$$s_n = \frac{n}{2}(a_1 + a_n).$$
