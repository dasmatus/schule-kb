# 🔑 TRUE RMS

TRUE RMS je spôsob merania efektívnej hodnoty striedavého napätia alebo prúdu, ktorý funguje presne aj pri nesinusoidálnom (skreslenom) priebehu signálu. Bežné meracie prístroje bez TRUE RMS môžu pri nelineárnej záťaži namerať nesprávnu hodnotu.
