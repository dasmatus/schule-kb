# 🔑 paralelizmus

Paralelizmus (súbežnosť) je štylistická figúra, pri ktorej majú po sebe idúce vety alebo verše rovnakú alebo podobnú stavbu, takže sa významovo porovnávajú. Typický je pre ľudovú slovesnosť, kde sa často kladie vedľa seba obraz z prírody a ľudský osud: „Keď počína dievča po poli krákoriť, // môžeš mu, mamička, periny hotoviť. // Keď počína dievča po poli spievati, // môžeš mu, mamička, čepce vyšívati.“ V rečníckom prejave vytvára rytmus a pomáha poslucháčovi zapamätať si myšlienku.
