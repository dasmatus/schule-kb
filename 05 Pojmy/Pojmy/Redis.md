# 🔑 Redis

Redis je rýchly databázový systém typu kľúč–hodnota, ktorý ukladá dáta priamo v [[RAM|pamäti RAM]] a používa sa ako aplikačná cache. Vďaka vysokej rýchlosti ho využívajú napríklad Twitter, GitHub alebo Stack Overflow.
