# 🔑 IP adresa

IP adresa je jedinečné číselné označenie zariadenia v počítačovej sieti, ktoré umožňuje jeho identifikáciu a komunikáciu s ostatnými zariadeniami. Skladá sa spravidla zo samotnej adresy, masky siete a brány (gateway).
