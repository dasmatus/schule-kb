# 🔑 CPU socket

CPU socket (pätica pre procesor) je konektor na [[Základná doska|základnej doske]], do ktorého sa vkladá procesor. Rôzne generácie a výrobcovia procesorov používajú odlišné typy socketov, napríklad AM4, AM5 alebo LGA 1200, pričom procesor musí byť s daným socketom kompatibilný.
