# 🔑 RAM

RAM (Random Access Memory) je operačná pamäť počítača, ktorá slúži na krátkodobé ukladanie dát aktívne používaných procesorom. Je volatilná – po vypnutí počítača sa jej obsah vymaže. Rýchlosť a kapacita RAM priamo ovplyvňujú výkon a plynulosť chodu systému.
