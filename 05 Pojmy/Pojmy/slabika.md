# 🔑 slabika

Slabika je najmenšia zvuková jednotka reči, ktorá je nositeľom [[prozodické vlastnosti reči|prozodických vlastností]] (dĺžky, prízvuku). Jej jadro tvoria samohlásky, [[dvojhláska|dvojhlásky]] alebo slabikotvorné spoluhlásky r, ŕ, l, ĺ, napr. vlk, krk, vŕba.
