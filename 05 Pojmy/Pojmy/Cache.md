# 🔑 Cache

Cache je rýchla pamäť, ktorá uchováva často používané dáta bližšie k procesoru alebo aplikácii, aby sa nemuseli počítať alebo načítavať znova z pomalšieho zdroja. Existuje na viacerých úrovniach – procesorová cache (L1/L2/L3), RAM, aplikačná cache (napr. [[Redis]]) aj databázová cache (napr. [[Buffer Pool]]). Keď sú dáta v cache, ide o cache hit, keď chýbajú, o cache miss.
