# Rekurentné postupnosti

> [!info] Zdroj
> Tabuľa z hodín 21. 9. a 22. 9. 2026. Pojem: [[Rekurentná postupnosť]].

Ďalší člen je zadaný pomocou predchádzajúcich a jedného alebo dvoch počiatočných členov. Členy sa počítajú postupným dosadzovaním. Nižšie sú úlohy z tabule (zvyčajne prvých päť alebo šesť členov).

## Prvého rádu

| Predpis | Počiatočný člen | Členy |
| --- | --- | --- |
| $a_{n+1} = a_n + 2$ | $a_1 = 10$ | $10,\ 12,\ 14,\ 16,\ 18$ |
| $a_{n+1} = 5 - a_n$ | $a_1 = -10$ | $-10,\ 15,\ -10,\ 15,\ \dots$ |
| $a_{n+1} = 3/a_n$ | $a_1 = 1$ | $1,\ 3,\ 1,\ 3,\ 1,\ 3,\ \dots$ |
| $a_{n+1} = a_n - 4$ | $a_1 = 6$ | $6,\ 2,\ -2,\ -6,\ -10$ |
| $a_{n+1} = a_n/5$ | $a_1 = 1$ | $1,\ \tfrac15,\ \tfrac1{25},\ \tfrac1{125},\ \tfrac1{625}$ |
| $a_{n+1} = 1/a_n$ | $a_1 = 1/10$ | $\tfrac1{10},\ 10,\ \tfrac1{10},\ 10,\ \tfrac1{10},\ 10$ |
| $a_{n+1} = 1/(1+a_n)$ | $a_1 = 1$ | $1,\ \tfrac12,\ \tfrac23,\ \tfrac35,\ \tfrac58,\ \tfrac8{13}$ |

## Druhého rádu

| Predpis | Počiatočné členy | Členy |
| --- | --- | --- |
| $a_{n+2} = a_n + a_{n+1}$ | $a_1=2$, $a_2=-3$ | $2,\ -3,\ -1,\ -4,\ -5,\ -9$ |
| $a_{n+2} = a_{n+1} - a_n$ | $a_1=11$, $a_2=3$ | $11,\ 3,\ -8,\ -11,\ -3,\ 8$ |
| $a_{n+2} = (a_n + a_{n+1})/2$ | $a_1=-1$, $a_2=-3$ | $-1,\ -3,\ -2,\ -\tfrac52,\ -\tfrac94,\ -\tfrac{19}{8}$ |
| $a_{n+2} = a_n^2 - a_{n+1}$ | $a_1=2$, $a_2=3$ | $2,\ 3,\ 1,\ 8,\ -7,\ 71$ |
| $a_{n+2} = \tfrac12(3a_{n+1}-a_n)$ | $a_1=2$, $a_2=1$ | $2,\ 1,\ \tfrac12,\ \tfrac14,\ \tfrac18,\ \tfrac1{16}$ |

Pri prvej úlohe druhého rádu: $a_3 = a_1+a_2 = 2+(-3) = -1$, $a_4 = a_2+a_3 = -3+(-1) = -4$.
