# OverTheWire Wargames

> [!info] Originál
> [overthewire.org/wargames](https://overthewire.org/wargames/) — obsah prevzatý november 2026, pozri pôvodný web pre aktuálne znenie.

Výukové security-cvicenia cez SSH. Stránka ukladá doporučené poradie hrania. Každá hra má vlastný SSH port (viď stránka hry).

## Obsah (hry a poradie, november 2026)

1. [Bandit](https://overthewire.org/wargames/bandit) — Unix/Linux podstawy
2. Prípadne vybrať:
   - [Natas](https://overthewire.org/wargames/natas) — web security
   - [Krypton](https://overthewire.org/wargames/krypton) — kryptografia
   - [Leviathan](https://overthewire.org/wargames/leviathan) — reverse engineering
3. [Narnia](https://overthewire.org/wargames/narnia) — začiatok binary exploitation
4. [Behemoth](https://overthewire.org/wargames/behemoth) a [Utumno](https://overthewire.org/wargames/utumno) — binary exploitation
5. Ďalšie: [Maze](https://overthewire.org/wargames/maze), [Vortex](https://overthewire.org/wargames/vortex), [Manpage](https://overthewire.org/wargames/manpage), [Drifter](https://overthewire.org/wargames/drifter), [FormulaOne](https://overthewire.org/wargames/formulaone)

## Ako použiť na maturitu

Hodí sa ku T07 v praxi: Bandit dá základy Linux príkazov, Natas prax v web security, Krypton kryptografii. Ďalšie hry (Narnia a vyššie) sú binary exploitation a reverse engineering — mimo rozsahu maturitných tém.
